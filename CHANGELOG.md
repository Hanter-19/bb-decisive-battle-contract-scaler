# 1.1.0
- Introduce 3 new configurations to adjust additional budget given to enemy noble and mercenary army generation, and ally noble army generation
- These modifiers are not affected by any multipliers, and the units are added after the the original armies have been generated
- Contract difficutly multiplier now set to 0 by default
- Added army simulation for allied army as well

# 1.0.0
- Introduces an additive multiplier to the contract difficulty of the Decisive Battle contract
- This value is adjustable in mod settings
- For testing, mod settings also has a button to simulate an army based on the multiplier and print the army composition to the logs
